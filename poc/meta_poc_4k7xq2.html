Click the button to start the proof-of-concept. To ensure the proof-of-concept works:
  • You need a dummy file named demo.html in the same directory.
  • You should be logged into a Facebook account in this browser session.
  • You should allow popups from this page.
  • Zoom at 100% (Ctrl+0). The browser window can be any size — the geometry adapts.
  • First run: open index.html?debug=1 to verify the red outline sits exactly on the blue Meta button. Do not click.
